Hướng dẫn nhập File (CSV):
  1. Bấm Tải File Mẫu về máy và mở bằng Excel.
  2. Nhập danh sách cán bộ vào file. (Không dùng dấu phẩy ",")
  3. Lưu file dưới dạng CSV (Comma delimited).
  4. Bấm Chọn File ở dưới và Upload lên hệ thống.
